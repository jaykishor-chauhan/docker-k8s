 # Dockerize the Getting Started Todo App

 This guide covers the common Docker workflows for the sample Todo app: running
 the development stack with Docker Compose, building and publishing a production
 image, and inspecting or managing containers.

 ## Guides

 1. [Run the development stack with Compose](docs/01-compose-workflow.md)
 2. [Build, publish, and pull the image](docs/02-image-workflow.md)
 3. [Inspect and manage containers](docs/03-container-operations.md)

 ## Prerequisites

 - Docker Desktop is installed and running.
 - PowerShell, Command Prompt, or a shell is available.
 - You have access to Docker Hub if you want to push an image.
